# 美团点金调价助手

> 篝火出品 · 收录于篝火 App 应用区

按昨日曝光分配每小时推广预算，给出点金出价建议，自动保存默认关闭

> 截图里的门店与全部数字都是虚构的「示例」。

## 风险与免责

- **自动修改推广出价会直接影响推广花费**，改错的钱不会退回。本工具**默认只显示建议**，自动保存出价默认关闭；在设置里打开时会二次确认，且仍受「单次步长、每日次数、最高出价上限」保护，重启后恢复为关闭。
- **美团后台改版后可能失效**：读页面和点「推广出价」弹窗依赖页面当前的结构，改版后可能读不到或点错。读不到时请用「手动填写」，不要依赖自动功能。页面读取与点击的步骤尚未在真实账号上做完整验收，请先用「只看建议、手动应用」小范围试用。
- **自动修改推广出价有违反平台规则的风险**，账号处罚等后果由使用者自己承担。使用前请自行确认平台规则。
- 登录状态只保存在本应用自带的窗口里，不读取、不同步你电脑上的浏览器；本工具不读取密码和 Cookie，数据只在本机处理，不上传到任何服务器。
- 「参考出价」是按预算占比估算的，不是平台承诺的效果。

## 怎么用

1. 点「打开美团窗口」，在弹出的窗口里登录美团外卖商家后台，进入「门店推广 → 点金」，停在要管的门店。
2. 回到本应用点「读取一次」（或「开始盯盘」，每 45 秒只读一次）。读到今日花费、当前出价；出价范围要在后台点开一次「推广出价」弹窗才读得到，读不到可在「手动填写页面数据」里填。
3. 填「日预算」（与后台一致）、营业时间（可「从页面读营业时间」，需停在门店管理页）、昨日分时曝光（可「从图表读取」，需停在「经营数据 → 流量」的昨日曝光人数图；横轴是 1–24 编号时要你确认含义；读不到就手动粘贴 24 个数字）。
4. 右侧显示今日进度、出价建议和每小时预算 / 参考出价。花费慢于计划建议小步加价，快于计划建议小步降价；营业时间外、预算用完、数据缺失或过期、冷却中都只会「保持」或「暂时不给建议」。
5. 想采纳建议：自己去后台改，或点「应用这条建议」（点一次改一次，改完会回读确认；对不上会停在「待核对」，要你填后台当前出价）。
6. 想让它自动改：展开「出价保护与自动调价」，填「最高出价上限」，勾选「自动调价」并确认风险。只在盯盘期间运行。
7. 「导出每小时计划（CSV）」可保存 24 小时预算与参考出价。

## 验收用例

以下用例不需要登录美团：

1. 点「手动填写页面数据」，填今日花费 58.44、当前出价 1.00、出价下限 0.10、出价上限 4.00；日预算填 200，营业时间 `09:00-21:00`，把 `samples/示例-曝光一行.txt` 的内容粘贴到曝光框（或用 `samples/示例-昨日曝光.txt`，每行「小时 数值」）。应得到：24 小时预算合计 200.00 元，0–8 点和 21–23 点为「休息」，11 点、18 点预算最高。
2. 上一步的数据是「示例」时间点之外读取的，建议显示「页面数据已过期 / 日期不是今天」属正常；需要在真实页面或当天读取后才有加减价建议。单元测试 `pnpm test` 用固定时间（北京时间 2026-10-27 14:00）验证：花费比计划少 30 元时建议 1.00 → 1.10，多 30 元时建议 1.00 → 0.90。
3. 营业时间文字 `samples/示例-营业时间.txt` 的规则：周二应得到 09:00–21:00，周六应得到 10:00–22:00（测试覆盖）。
4. 默认「自动调价」为关闭；没填「最高出价上限」时点开关会提示先填写；填写后点开关会弹出风险确认，勾选后才能打开。
5. `pnpm test` 共 57 项，覆盖出价范围上下限、预算用超、营业时间外、数据缺失、冷却、每日次数、回滚、回读核对和自动保护。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
